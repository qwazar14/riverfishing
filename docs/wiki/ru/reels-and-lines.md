# Катушки, лески и поводки

Катушка решает, какой у вас фрикцион и какой толщины леску можно на неё намотать; леска решает, какой вес вы вытянете до обрыва и насколько сильно она пугает рыбу.

### Кривая фрикциона

Пресноводная лестница линейна; солёные размеры взбираются круче, потому что океанская рыба на порядок
тяжелее и линейный фрикцион её попросту не остановит:

```
size ≤ 7000 :  drag = size / 1000
size > 7000 :  drag = 7.0 + (size − 7000) / 1000 × 2.5
```

Итого 1000 → 1 кг и так до 7000 → 7 кг, затем 8000 → 9.5 кг, 10000 → 14.5 кг, 12000 → 19.5 кг,
14000 → 24.5 кг. Подсказка и вываживание читают одну и ту же цифру.

> До 0.6.0 не читали: вываживание считало собственный простой `size / 1000`, так что 14000 обещала
> 24.5 кг, а выдавала 14.0, и весь солёный бонус существовал только в подсказке. Пресной воды это не
> касалось — на 7000 и ниже обе формулы сходятся.

Что фрикцион на самом деле делает при вываживании:

- Добавляет `0.5 × drag` сверху к тесту лески на разрыв при расчёте запаса прочности.
- **Быстрее стравливает леску**, когда вы отпускаете: `relaxTick = 0.010 + clamp(drag/10, 0, 0.5) × 0.02`. Крупная катушка сбрасывает натяжение в **1.67 раза** быстрее, чем 1000; ограничитель упирается в 5 кг фрикциона, так что все катушки от 5000 и выше сбрасывают одинаково.
- **Характер катушки**: маленькие дёрганые, большие грубые, но гасящие. `sensitivity = clamp(1 + (4000 − size)/4000 × 0.5, 0.6, 1.5)`. 1000 сидит на 1.375, 4000 — на 1.0, 14000 — на нижнем пороге 0.6. Удочка **без катушки** сидит на жёстко зашитых 1.3 — дёрганая, но чуть спокойнее 1000.
- Немного ускоряет подъём рыбы: в `landPulse` заложен член `0.9 + size/14000`.

### Правило диаметра шпули

Шпуля держит леску только до определённого диаметра. В экране сборки это **жёсткое** правило — слишком толстая леска просто не вставится.

```
maxLineDiameter(mm) = 0.15 + reelSize / 1000 × 0.05
```

1000 → 0.20 мм, дальше +0.05 мм на каждые 1000: 7000 → 0.50 мм, 14000 → 0.85 мм.

**Минимальная** цифра в подсказке — чисто справочная: более тонкая леска встанет, просто недоберёт шпулю:

```
minLineDiameter(mm) = max(0.06, maxLineDiameter − 0.14)
```

Дневник заодно показывает самую маленькую катушку, которая примет данную леску, но этот поиск перебирает только размеры 1000–7000, поэтому для лесок от 0.55 мм и толще он не выдаёт ничего.

## Лески

Три материала. Тест на разрыв растёт как **квадрат** диаметра:

```
breaking strain (kg) = 100 × diameter² × materialFactor
```

| Материал | Коэффициент прочности | Коэффициент заметности | Характер |
|---|---|---|---|
| моно (нейлон) | 1.00 | 1.00 | Базовый универсал. |
| флюорокарбон | 1.10 | 0.45 | Показатель преломления близок к воде — почти невидим и чуть прочнее. |
| плетёнка (Dyneema) | 3.00 | 1.45 | Чудовищно прочна для своего диаметра, но непрозрачна и очень заметна. |

Флюорокарбон вдобавок **изнашивается на 40 % медленнее** двух остальных.

### Заметность лески

Толстая непрозрачная леска тормозит клёв — и мелкую осторожную рыбу это заботит куда сильнее, чем крупную.

```
visibility = materialVisibility × (diameter / 0.20)
if visibility > 1:
    sensitivity = clamp(1.5 − meanWeightKg × 0.5, 0.1, 1.5)
    bite weight ×= max(0.4, 1 − 0.25 × (visibility − 1) × sensitivity)
```

Моно 0.20 мм — точка отсчёта (заметность ровно 1, штрафа нет). Плетёнка 0.30 мм сидит на 2.18 — настоящая гиря на плотвином месте и почти незаметная мелочь для сома. Флюорокарбон любого разумного диаметра остаётся ниже 1 и не штрафуется никогда.

Отдельно: попадание в **предпочитаемый материал** вида стоит 1.0 в оценке соответствия снасти против 0.6 при промахе, а диаметр оценивается спадом вокруг идеала этого вида.

### Износ лески

Леска несёт значение износа от 0 % до 100 %, показанное в подсказке, и оно путешествует вместе со стопкой лески.

```
breaking strain multiplier = 1 − 0.55 × (wear / 100)
```

При износе 100 % леска сохраняет лишь 45 % своего теста, а подсказка краснеет: *«Леска изношена — может порваться в любой момент!»*

Откуда берётся износ (на пресете *реализма* по умолчанию):

| Событие | Износ лески |
|---|---|
| Каждый заброс | +0.1 (дробно; +0.06 на флюорокарбоне) — накапливается вероятностно |
| Отцеп с зацепа | +3 |
| Мёртвый зацеп с потерей оснастки | +6 |
| Каждые ~15 тиков сверх предела снасти | +1 |
| Обрыв лески | +1 |
| Катастрофический отказ снасти на подсечке | +5 |
| Пустая подсечка тупым крючком | +1 |

**Чинить леску нечем** — изношенную просто меняют.

### Рецепты лесок

Основа любой цепочки — **кольцо из 8 нитей** в сетке крафта.

| Результат | Рецепт |
|---|---|
| Монолеска 0.10 ×2 | Кольцо из 8 × Нить (пустой центр) |
| Плетёнка 0.16 ×2 | Кольцо из 8 × Нить + Мембрана фантома в центре |
| Флюорокарбон 0.14 ×2 | Кольцо из 8 × Нить + Осколок аметиста в центре |
| Любая леска толще ×1 | Кольцо из 8 × Нить + **предыдущая леска того же материала** в центре |

Цепочки улучшения, по шагу на крафт:

- **Моно:** 0.10 → 0.14 → 0.18 → 0.25 → 0.30 → 0.40 → 0.50 → 0.60 → 0.70 → 0.80
- **Плетёнка:** 0.16 → 0.20 → 0.25 → 0.30 → 0.40 → 0.50 → 0.60
- **Флюорокарбон:** 0.14 → 0.16 → 0.20 → 0.25 → 0.30 → 0.40

[Рыбак](villager.md) тоже торгует: моно 0.14 и 0.18 на низких уровнях, плетёнка 0.16 / флюорокарбон 0.20 у подмастерья, флюорокарбон 0.30 у эксперта и весь тяжёлый ярус у мастера.

## Поводки

Поводок — отдельный предмет, который вставляется в **слот поводка** Хищной или Сомовьей оснастки. Пятнадцать видов достаточно зубасты, чтобы перекусить голую леску: щука, судак, морской угорь, ваху, барракуда, акула-мако, таймень, арапайма, белуга, луфарь, тупорылая акула, плащеносная акула, золотой дорадо, голиафовый групер и пирайба.

| Поводок | ID предмета | Защита от перекуса | Незаметность | Рецепт |
|---|---|---|---|---|
| Стальной поводок | `leader` | 100 % | 10 % | Нить + Кусочек железа |
| Флюорокарбоновый поводок | `leader_fluoro` | 85 % | 90 % | Нить + Осколок призмарина |
| Титановый поводок | `leader_titanium` | 100 % | 60 % | Нить + Железный слиток |

**Защита** проверяется один раз, в момент, когда рыба села, и только для видов, которым поводок обязателен:

```
bite-off chance = 0.75 × (1 − protection)        (0.75 is the realism preset)
```

То есть вовсе без поводка против щуки — это **75 % шанс**, что леску перекусят и вы потеряете и рыбу, *и* оснастку; флюорокарбоновый поводок роняет это до 11 %; сталь и титан делают перекус невозможным.

**Незаметность** работает на шанс клёва по всем видам, пока поводок стоит:

```
bite weight ×= 0.85 + stealth × 0.30
```

| Поставленный поводок | Множитель клёва |
|---|---|
| Стальной | ×0.88 |
| Титановый | ×1.03 |
| Флюорокарбоновый | ×1.12 |

Донную и поплавочную ловлю без поводка это никак не штрафует — множитель применяется только тогда, когда поводок реально стоит в оснастке. Отдельно: вид, которому поводок *обязателен*, получает ровный штраф **×0.15** к клёву, если вы ловите его без поводка.
