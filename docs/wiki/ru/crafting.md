# Справочник по крафту

Все рецепты, которые добавляет мод. У рецептов по форме схема сетки записана как `ряд / ряд / ряд`, где `·` — пустая клетка.

У предметов с пометкой **только торговля** или **только задание** рецепта нет вовсе — см. [Житель](villager.md) и [Прогрессия](progression.md).

---

## Удилища

С 0.10.0 крафтятся только четыре простейших бланка; все остальные удилища **покупаются в сборе у [рыбака](villager.md)** (строка «как получить» в дневнике так и говорит). Все — по форме; бланку с катушкой нужна нить на обмотку пропускных колец.

| Удилище | Схема | Обозначения |
|---|---|---|
| Удочка из палки | `··S / ·S· / S··` | S = Палка |
| Маховое удилище | `··b / ·b· / is·` | b = Бамбук, i = Железный слиток, s = Нить |
| Ультралайт | `··b / sb· / i··` | b = Бамбук, s = Нить, i = Железный слиток |

**Только торговля:** Бамбуковая, Зимняя, Спиннинг, Фидерное, Донное, Карповое, Морской спиннинг, Сёрфовое, Лодочное и Троллинговое. Материалы для ремонта на наковальне перечислены в [Удилищах](rods.md).

---

## Катушки

Крафтятся две, без формы; остальные девять (2000, 3000, 5000, 6000, 7000, 8000, 10000, 12000, 14000) — **только торговля**: их продаёт [рыбак](villager.md), а две приходят наградами за [задания](progression.md#цепочка-заданий).

| Катушка | Ингредиенты |
|---|---|
| Катушка 1000 | 2 × Железный слиток + Редстоуновая пыль |
| Катушка 4000 | 3 × Железный слиток + Медный слиток + 2 × Редстоуновая пыль |

Предмета «Катушка 9000» не существует.

---

## Лески

Все — по форме, вокруг **кольца из 8 Нитей** (`SSS / S?S / SSS`).

| Результат | Центр кольца |
|---|---|
| Монолеска 0.10 **×2** | *(пусто)* |
| Флюорокарбон 0.14 **×2** | Осколок аметиста |
| Следующий диаметр **×1** | Предыдущая леска того же материала |

У Плетёнки 0.16 рецепта больше нет — её продаёт [рыбак](villager.md). Цепочки улучшений, один крафт на шаг; диаметр **жирным** не крафтится — его покупают, и цепочка идёт дальше от него:

| Материал | Цепочка |
|---|---|
| Моно | 0.10 → 0.14 → 0.18 → 0.25 → 0.30 → 0.40 · **0.50, 0.60, 0.70, 0.80** только торговля |
| Плетёнка | **0.16** → 0.20 → 0.25 · **0.30, 0.40, 0.50, 0.60** только торговля |
| Флюорокарбон | 0.14 → 0.16 · **0.20** → 0.25 → 0.30 · **0.40** только торговля |

### Ремонт лески

Любая леска в **центре** сетки и **четыре Нити** по её четырём сторонам (`·S· / SLS / ·S·`) возвращают ту же леску **свежей** — [износ](reels-and-lines.md) снят. Любой диаметр любого материала, куплена она или скрафчена.

## Крючки

Все — без формы. Чем больше номер, тем меньше крючок.

| Результат | Ингредиенты |
|---|---|
| Крючок №16 **×2** | Кусочек железа |
| Крючок №14 | Крючок №16 + Кусочек железа |
| Крючок №12 | Крючок №14 + Кусочек железа |
| Крючок №10 | Крючок №12 + Кусочек железа |
| Крючок №8 | Крючок №10 + Кусочек железа |
| Крючок №6 | Крючок №8 + Кусочек железа |
| Крючок №4 | Крючок №6 + Кусочек железа |
| Крючок №2 | **только торговля** (рыбак уровня «Мастер») |
| Крючок №1 | **только торговля** (рыбак уровня «Мастер») |

Все девять размеров крючков составляют тег `riverfishing:hooks`, который используют рецепты приманок. Учтите: у №2 и №1 своего рецепта нет — единственный их источник — рыбак уровня «Мастер».

## Оснастки

**Ни у одной оснастки нет рецепта крафта.** Шесть сменных донных — Донная, Фидерная, Флет-фидер, Груша, Карповая и Сомовья — вяжутся на **[снастевом станке](tackle-station.md)** под тот вес, который выбрали вы, а именно вес и должен попасть в [тестовое окно](rods.md#загрузка-бланка-тестовое-окно) вашего бланка; приходят они с уже вставленными крючками. (До 0.10.0 связанная руками оснастка выходила с подстановочной массой, выбора не давали, так что рецепты в сетке не учили ничему, чему станок не учит лучше.)

Примитивная, Лёгкая поплавочная, Поплавочная, Зимняя и Хищная оснастки встроены в свои бланки — их нельзя ни изготовить, ни взять в руки.

## Поводки и поплавок

Все — без формы.

| Предмет | Ингредиенты |
|---|---|
| Стальной поводок | Нить + Кусочек железа |
| Флюорокарбоновый поводок | **только торговля** — у [рыбака](villager.md) |
| Титановый поводок | **только торговля** — у рыбака, либо наградой за [задание](progression.md#цепочка-заданий) |
| Поплавок | Бамбук + Перо |

## Приманки

**Ни у одной приманки нет рецепта в сетке** — ни у вращалки, ни у колебалки, ни у семейства воблеров, джига, кастмастера, спиннербейта, цикады, свимбейта, вэки-червя, поппера, крэнка или мормышки. Их **вяжут на [снастевом станке](tackle-station.md)** — задаёте граммы, получаете настоящий размер и крючок по своему выбору — либо покупают у [рыбака](villager.md). (У приманки из сетки не было штампа веса, и игра читала её как 0 г: к забросу ничего, [фильтру по размеру приманки](tackle-station.md#2-фильтр-по-размеру-приманки-только-приманки) читать нечего. Держать такое смысла не было.) Два самых тяжёлых класса (морские размеры) есть только на станке. Единственный оставшийся рецепт для приманок — покраска:

### Покраска приманки

**Особый рецепт**: любая одна искусственная приманка плюс одна или несколько **красок** в сетке, в любых клетках, — и приманка возвращается со смешанным цветом, ровно как кожаная броня. См. [цвет приманки](rigs-and-baits.md#покраска-приманок).

## Наживки

| Наживка | Тип | Ингредиенты |
|---|---|---|
| Тесто | без формы | Пшеница + Ведро воды |
| Хлебный мякиш **×4** | без формы | 1 × Хлеб |
| Бойлы **×4** | без формы | 2 × Пшеница + Яйцо + Сахар |
| Живец | **особый** | Одна пойманная рыба весом **не более 150 г**, одна в сетке — наживка сохраняет вес рыбы |

Червяк, Опарыш, Мотыль и Куриная печень добываются копанием и с мобов; Кукуруза, Горох и Перловка — с [наживочных грядок](blocks.md#наживочные-культуры). См. [Инструменты](tools.md#откуда-берётся-наживка).

## Прикормка

| Прикормка | Тип | Ингредиенты |
|---|---|---|
| Базовая прикормка **×2** | бесформенный | Семена пшеницы + Хлеб — *основа; всё остальное [подмешивают](groundbait.md) в неё* |
| Прикормочный грунт **×4** | бесформенный | Земля — *балласт, которым смесь делают постнее* |
| Любая смесь | бесформенный | Базовая прикормка + до 8 компонентов в сетке — один слот это один предмет, а съедобный предмет на входе это прикормка на выходе |

## Блоки

| Блок | Тип | Ингредиенты |
|---|---|---|
| Рыболовный прилавок | без формы | Бочка + 2 × Нить + Железный слиток |
| Род-под (1 слот) | по форме `s·s / ·s· / ·s·` | s = Палка |
| Род-под (3 слота) | по форме `n·n / iii / i·i` | n = Кусочек железа, i = Железный слиток |
| Малявочник | по форме `s·s / shs / s·s` | s = Палка, h = Нить |
| Червятник | по форме `PPP / PDP / PPP` | P = любые доски, D = Земля |
| Ферма опарыша | по форме `PPP / PFP / PPP` | P = любые доски, F = Гнилая плоть |
| Аквариум | по форме `GWG / RKR / PSP` | G = Стекло, W = Ведро воды, R = Гравий, K = Ламинария, P = любые доски, S = любая табличка |
| Мини-аквариум | — | **рецепта нет** |

## Готовка

| Результат | Способ | Что кладём | Время | XP |
|---|---|---|---|---|
| Жареное филе | Коптильня | Сырое филе | 100 тиков | 0.2 |
| Жареное филе | Печь | Сырое филе | 200 тиков | 0.2 |
| Жареное филе | Костёр | Сырое филе | 600 тиков | 0.2 |

Сырое филе даёт [Филейный нож](tools.md#филейный-нож) — по одному на каждые 200 г рыбы, но не больше стака с одного экземпляра. Этот же предмет — универсальная морская насадка и компонент прикормки.
