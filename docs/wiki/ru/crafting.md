# Справочник по крафту

Все рецепты, которые добавляет мод. У рецептов по форме схема сетки записана как `ряд / ряд / ряд`, где `·` — пустая клетка.

У предметов с пометкой **только торговля** или **только задание** рецепта нет вовсе — см. [Житель](villager.md) и [Прогрессия](progression.md).

---

## Удилища

Все — по форме. Каждому бланку с катушкой нужна нить на обмотку пропускных колец.

| Удилище | Схема | Обозначения |
|---|---|---|
| Удочка из палки | `··S / ·S· / S··` | S = Палка |
| Бамбуковая удочка | `··b / ·b· / b··` | b = Бамбук |
| Зимняя удочка | `··N / ·S· / S··` | N = Кусочек железа, S = Палка |
| Маховое удилище | `··b / ·b· / is·` | b = Бамбук, i = Железный слиток, s = Нить |
| Ультралайт | `··b / sb· / i··` | b = Бамбук, s = Нить, i = Железный слиток |
| Спиннинг | `··b / si· / i··` | b = Бамбук, s = Нить, i = Железный слиток |
| Фидерное удилище | `··g / si· / ii·` | g = Золотой слиток, s = Нить, i = Железный слиток |
| Донное удилище | `·gg / si· / ii·` | g = Золотой слиток, s = Нить, i = Железный слиток |
| Карповое удилище | `··d / si· / ig·` | d = Алмаз, g = Золотой слиток, s = Нить, i = Железный слиток |
| Морской спиннинг | `··p / si· / id·` | p = Осколок призмарина, d = Алмаз, s = Нить, i = Железный слиток |
| Сёрфовое удилище | `·pp / si· / id·` | p = Осколок призмарина, d = Алмаз, s = Нить, i = Железный слиток |
| Лодочное удилище | `··c / si· / id·` | c = Кристалл призмарина, d = Алмаз, s = Нить, i = Железный слиток |
| Троллинговое удилище | `··n / si· / id·` | n = Раковина наутилуса, d = Алмаз, s = Нить, i = Железный слиток |

Четыре морских различаются только **вершинкой**. Материалы для ремонта на наковальне перечислены в [Удилищах](rods.md).

| Катушка 7000 | 5 × Железный слиток + 2 × Медный слиток + 2 × Редстоуновая пыль |

## Лески

Все — по форме, вокруг **кольца из 8 Нитей** (`SSS / S?S / SSS`).

| Результат | Центр кольца |
|---|---|
| Монолеска 0.10 **×2** | *(пусто)* |
| Плетёнка 0.16 **×2** | Мембрана фантома |
| Флюорокарбон 0.14 **×2** | Осколок аметиста |
| Следующий диаметр **×1** | Предыдущая леска того же материала |

Цепочки улучшений, один крафт на шаг:

| Материал | Цепочка |
|---|---|
| Моно | 0.10 → 0.14 → 0.18 → 0.25 → 0.30 → 0.40 → 0.50 → 0.60 → 0.70 → 0.80 |
| Плетёнка | 0.16 → 0.20 → 0.25 → 0.30 → 0.40 → 0.50 → 0.60 |
| Флюорокарбон | 0.14 → 0.16 → 0.20 → 0.25 → 0.30 → 0.40 |

## Крючки

Все — без формы. Чем больше номер, тем меньше крючок.

| Результат | Ингредиенты |
|---|---|
| Крючок №16 **×2** | Кусочек железа |
| Крючок №14 | Крючок №16 + Кусочек железа |
| Крючок №12 | Крючок №14 + Кусочек железа |
| Крючок №10 | Крючок №12 + Кусочек железа |
| Крючок №8 | Крючок №10 + Кусочек железа |
| Крючок №6 | Крючок №8 + Кусочек железа |
| Крючок №4 | Крючок №6 + Кусочек железа |
| Крючок №2 | **только торговля** (рыбак уровня «Мастер») |
| Крючок №1 | **только торговля** (рыбак уровня «Мастер») |

Все девять размеров крючков составляют тег `riverfishing:hooks`, который используют рецепты приманок. Учтите: у №2 и №1 своего рецепта нет — единственный их источник — рыбак уровня «Мастер».

## Оснастки

> **Это базовые рецепты.** Оснастка, связанная руками, выходит с подстановочной массой своего типа —
> выбора вам не дают. Если нужна оснастка **того веса, который выбрали вы**, вяжите её на
> **[снастевом станке](tackle-station.md)**. Настоятельно рекомендуется: именно вес и должен попасть в
> [тестовое окно](rods.md#загрузка-бланка-тестовое-окно) вашего бланка, а станковые оснастки
> приходят с уже вставленными крючками.

Крафтятся только шесть сменных донных оснасток. Примитивная, Лёгкая поплавочная, Поплавочная, Зимняя и Хищная оснастки встроены в свои бланки — их нельзя ни изготовить, ни взять в руки.

| Оснастка | Тип | Ингредиенты |
|---|---|---|
| Донная оснастка | без формы | Нить + 2 × Кусочек железа |
| Фидерная оснастка | по форме `n·n / nsn` | n = Кусочек железа, s = Нить |
| Флет-фидер | по форме `nnn / nsn` | n = Кусочек железа, s = Нить |
| Груша (3 крючка) | без формы | 3 × Нить + 2 × Кусочек железа |
| Карповая оснастка | без формы | 2 × Нить + Сгусток слизи + Кусочек железа |
| Сомовья оснастка | без формы | 2 × Нить + Железный слиток + Кусочек железа |

Все шесть можно связать и на [снастевом станке](tackle-station.md) под выбранный вес — там они приходят с уже вставленными крючками.

## Приманки

> **Это базовые рецепты, и они стоят вам массы приманки.** У приманки ручного крафта **нет штампа
> веса**, и игра читает её как **0 г** — она ничего не добавляет к забросу и не запускает
> [фильтр по размеру приманки](tackle-station.md#2-фильтр-по-размеру-приманки-только-приманки), а значит никогда не
> подбирает себе рыбу. Вяжите приманки на **[снастевом станке](tackle-station.md)** — задаёте граммы,
> получаете настоящий размер. Два самых тяжёлых класса (морские размеры) есть только там.

Ингредиент `h` — это тег `riverfishing:hooks` (№16–№4).

| Приманка | Тип | Ингредиенты |
|---|---|---|
| Вращающаяся блесна | по форме `n / i / h` | n = Кусочек железа, i = Железный слиток, h = крючок |
| Колеблющаяся блесна | по форме `g / h` | g = Золотой слиток, h = крючок |
| Кастмастер | без формы | 2 × Железный слиток + крючок |
| Крэнк | без формы | Железный слиток + Кусочек железа + крючок |
| Джиг | без формы | Железный слиток + Нить + крючок |
| Поппер | без формы | Кусочек железа + Бамбук + крючок |
| Воблер | — | **[Снастевой станок](tackle-station.md)** или рыбак (уровень «Эксперт») |
| Силиконовая приманка | — | **[Снастевой станок](tackle-station.md)** или рыбак (уровень «Специалист») |

### Покраска приманки

**Особый рецепт**: любая одна искусственная приманка плюс одна или несколько **красок** в сетке, в любых клетках, — и приманка возвращается со смешанным цветом, ровно как кожаная броня. См. [цвет приманки](rigs-and-baits.md#покраска-приманок).

## Наживки

| Наживка | Тип | Ингредиенты |
|---|---|---|
| Тесто | без формы | Пшеница + Ведро воды |
| Хлебный мякиш **×4** | без формы | 1 × Хлеб |
| Бойлы **×4** | без формы | 2 × Пшеница + Яйцо + Сахар |
| Мормышка | без формы | Кусочек золота + любой крючок №16–№4 + 2 × Нить |
| Живец | **особый** | Одна пойманная рыба весом **не более 150 г**, одна в сетке — наживка сохраняет вес рыбы |

Червяк, Опарыш, Мотыль и Куриная печень добываются копанием и с мобов; Кукуруза, Горох и Перловка — с [наживочных грядок](blocks.md#наживочные-культуры). См. [Инструменты](tools.md#откуда-берётся-наживка).

## Готовка

| Результат | Способ | Что кладём | Время | XP |
|---|---|---|---|---|
| Жареное филе | Коптильня | Сырое филе | 100 тиков | 0.2 |
| Жареное филе | Печь | Сырое филе | 200 тиков | 0.2 |
| Жареное филе | Костёр | Сырое филе | 600 тиков | 0.2 |

Сырое филе даёт [Филейный нож](tools.md#филейный-нож) — по одному на каждые 300 г рыбы, но не больше стака с одного экземпляра.
