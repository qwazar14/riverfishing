# River Fishing — Вики

**River Fishing** превращает рыбалку в процесс вместо клика по воде. Удочку вы собираете сами: бланк, катушка, леска, оснастка; наживку, размер крючка, прикормку и поводок подбираете под ту рыбу, которую действительно хотите взять; читаете водоём, сезон, время суток и барометр — а потом вываживаете то, что село.

Просто так, на удачу, здесь не клюёт. Управляемый данными движок клёва взвешивает всю вашу снасть против каждого из **79 видов** при текущих условиях и решает, и *кто* возьмёт, и *сколько вы будете ждать*. Несогласованная снасть не ловит ничего, слишком заметная леска отпугивает мелкую осторожную рыбу, крупная требует почти безупречного комплекта, а в каждом водоёме мира — своё сообщество видов, закреплённое сидом мира.

## Коротко

1. **Соберите удочку.** Бланк + (катушка) + леска + оснастка. Sneak + ПКМ по удочке — открыть сборку. На бланках под катушку катушка ставится **раньше** лески.
2. **Зарядите оснастку.** Крючок и наживка — или поводок и приманка. Хищник берёт только искусственные приманки, мирная рыба — только натуральную наживку.
3. **Подбирайте под рыбу, а не под водоём.** У каждого вида есть свои идеальные удилища, оснастки, размеры крючка, леска и наживки. Чем крупнее рыба, тем больше пунктов из этого списка должно совпасть.
4. **Забрасывайте по шкале.** Зажмите, чтобы копить силу, отпустите на пике.
5. **Смотрите, а не слушайте.** Ни звука поклёвки, ни надписи о ней нет — поплавок просто уходит под воду.
6. **Вываживайте фрикционом.** Мотайте, когда рыба спокойна, отпускайте на рывке, приседайте, чтобы сдать фрикцион на свече или нырке.
7. **Отпускайте трофеи.** [Зарыбление](stocking.md) — это то, чем водоём остаётся богатым.

| Стиль | Бланки | В чём игра |
|---|---|---|
| **Поплавок** | Палка, бамбук, мах, зимняя | Заметить нырок поплавка, потом выиграть тайминг выхвата |
| **Донка** | Фидер, донное, карповое, сёрфовое, лодочное | Дальние забросы, долгое терпеливое ожидание, род-поды и сигнализаторы |

## Как читать это офлайн

Эти страницы — обычный Markdown: GitHub и любой редактор рисуют их как есть, а таблица видов
несёт спрайты прямо в строках.

Есть ещё **одностраничная сборка**, где всё в одном файле: боковое меню, поле фильтра и каждый
рецепт крафта нарисован настоящей сеткой 3×3, а не расписан строкой-шаблоном. Собирается из корня
репозитория:

```
python tools/gen_wiki_bundle.py --out build/wiki.html
python tools/gen_wiki_bundle.py --out build/wiki.html --mc-jar <a Minecraft client jar>
```

Сетки генерируются из JSON рецептов, так что разойтись с тем, что грузит игра, они не могут. С ключом
`--mc-jar` ванильные ингредиенты показываются своими настоящими иконками, вычитанными из этого jar
при сборке; без него они рисуются подписанными цветными плитками, и всё точно так же работает. Ничего
из jar в репозитории не хранится — искусство Mojang не наше, чтобы его раздавать, — поэтому собранная
страница не коммитится в ветку с исходниками. Опубликованная копия лежит на сгенерированной ветке
`gh-pages`, куда её кладёт `tools/publish_pages.py`.

## Для сборщиков модпаков

Каждый вид — это один JSON-файл в `data/riverfishing/fish_profiles/<species>.json`, и **всё в нём переопределяется датапаком**: где рыба живёт, что ест, как сопротивляется, насколько редка, какой уровень нужен. Движок клёва, страницы дневника, записи JEI и ограничения у торговца читают один и тот же файл, так что ваши правки останутся согласованными везде.

Схема с комментариями лежит в [`docs/FISH_PROFILES.md`](../../FISH_PROFILES.md).
