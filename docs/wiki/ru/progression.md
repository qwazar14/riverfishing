# Прогресс

Ваши записи хранятся в **Рыболовном дневнике**: каждый пойманный вид, лучший экземпляр по каждому из них, XP и уровень рыболова, очки навыков и цепочка заданий. Смерть их не стирает.

## XP рыболова

Каждая **зачётная** рыба приносит:

```
xp = 2 + weightGrams / 25 + lengthCm / 4        (целочисленное деление)
   + 50 если вид ещё ни разу не был взят
   + 20 если это личный рекорд по этому виду (и вид не новый)
   × 3 если это трофей
```

[Забагренная](fishing-mechanics.md#багрение) рыба не приносит вообще ничего и в дневник не попадает.

Вес в этой формуле главный, и так задумано: стая мелочи даёт мало XP в час, а охота за крупной рыбой окупается.

| Средний экземпляр… | Вес / длина | XP |
|---|---|---|
| Уклейка | 30 г / ~10 см | 5 |
| Плотва | 120 г / ~16 см | ~10 |
| Лещ | 900 г / ~35 см | ~46 |
| Карп | 3.5 кг / ~58 см | ~156 |
| Сом | 7 кг / ~96 см | ~306 |

(У длины есть ±2 % естественного разброса, так что XP гуляет на пункт-два.)

XP дают ещё две вещи: **подсачить рыбу товарищу** (+5) и **выловить сокровище** (+15).

## Что открывает уровень

Уровень — это мягкий барьер сложности в моде. У каждого вида прописан `min_angler_level`, и каждый недостающий уровень обходится дорого:

```
вес поклёвки ×= max(0.03, 0.6 ^ levelsShort)
```

Недобор двух уровней — это ×0.36, пяти — ×0.08, а нижний предел — 3 %. Крупную рыбу *можно* выхватить и рано, с правильной снастью в правильном месте — просто это редкость, а с уровнем становится нормой.

## Навыки

Каждый уровень рыболова даёт **одно очко навыков**. Шесть перков, у каждого **5 уровней**, так что полное дерево стоит 30 очков — то есть 30-й уровень.

Тратить их — на вкладке **Навыки** в дневнике. Очки не возвращаются (сбрасывает только `/rffish reset`, вместе со всем остальным).

| Перк | Ветка | За уровень | На 5-м уровне |
|---|---|---|---|
| **Бережливость** | Наживка | +5 % шанс сохранить наживку после поклёвки | 25 % |
| **Чуткость** | Чуткость | −5 % к времени до поклёвки | −25 % |
| **Натуралист** | Знание | +5 % к общему шансу клёва | +25 % |
| **Крепкая рука** | Рука | +5 % нагрузки на леску до обрыва | +25 % |
| **Рыбацкая удача** | Удача | +1 % к шансу трофея | +5 % |
| **Умение** | Умение | +1 % к ширине зоны подсечки | +5 % |

Бонус Натуралиста применяется одинаково к весу поклёвки всех видов; Крепкая рука умножает ваш порог обрыва; Умение расширяет зелёную зону на любой [шкале подсечки](fishing-mechanics.md#шкала-подсечки).

## Цепочка заданий

Восемь стадий: **51 задача** плюс по одному призу за полное прохождение каждой стадии, всего 59 записей. Задания **выводятся на ходу** из вашего дневника, так что «принимать» их не нужно.

- Выполненная цель один раз объявляется в чате: *«Задание выполнено: … — награда ждёт в дневнике!»*
- Награду вы **забираете** сами, щёлкнув по заданию на вкладке **Задания** в дневнике.
- Последняя запись каждой стадии (*«Заверши стадию N полностью»*) — бонусный приз за все её задачи.
- Стадия становится **видимой и доступной**, когда выполнено **70 %** задач предыдущей. У закрытых стоит *«Закрыто — заверши стадию N»*.

## Достижения

Двадцать два достижения. Часть срабатывает просто от наличия рыбы в инвентаре, остальные **прописаны в коде** и зависят от того, *как* она поймана.

| Достижение | Как |
|---|---|
| **Речная рыбалка** (корень) | Иметь любую рыбу из мода |
| **Десяток в садке** | 10 разных видов |
| **Четверть сотни** | 25 разных видов |
| **Полсотни видов** | 50 разных видов |
| **Полный бестиарий** *(испытание)* | Все виды — кои не в счёт |
| **Трофейный экземпляр** *(цель)* | **Взять** трофейный экземпляр самому |
| **Зубастая** | Иметь щуку |
| **Хозяин ямы** *(цель)* | Иметь сома |
| **Царская рыба** *(испытание)* | Иметь стерлядь |
| **Король зимней ночи** *(цель)* | Иметь налима |
| **Речной боец** *(испытание)* | Иметь сазана |
| **Живая драгоценность** *(цель)* | Иметь любого кои |
| **Коллекционер кои** *(испытание)* | Все пять кои: Кохаку, Танчо, Сёва, Асаги, Бекко |
| **Мастер-рыболов** *(испытание)* | Достичь ранга Мастер |
| **Имя в истории** | Поймать [легендарную рыбу](fishing-mechanics.md#легендарные-рыбы) |
| **Дедовским способом** | Взять **щуку 4+ кг на живца** Удочкой из палки или Бамбуковой удочкой |
| **Из-подо льда** | Вытащить **налима** через лунку зимней удочкой |
| **Голыми руками** | Взять **трофей** снастью без катушки — Удочкой из палки, Бамбуковой или Маховой |
| **В самый жор** | Поймать рыбу во время [жора](water-and-conditions.md#жор) |
| **Улов десятилетия** | Выловить старый сапог |
| **Бессердечный повар** | Пустить карпа кои на филе |
| **А она точно была огромная** *(скрытое)* | Схватить те самые 0.3 % [катастрофического отказа снасти](fishing-mechanics.md#катастрофический-обрыв) |

Достижения на число видов **считаются в коде** по живому списку видов, так что разойтись с обновлением контента они не могут. Кои в этот счёт не входят.

*Трофейный экземпляр* с 0.7.0 тоже прописан в коде: он выдаётся в момент, когда трофей взят, — и говорит наконец то, что всегда имел в виду: его получают за поимку, а не за то, что трофей тебе кто-то вручил. (Раньше это был предикат предмета из датапака, а на 1.21.1 такой предикат разбирался в пустой — а пустой подходит к любому предмету на свете. Достижение выдавали за подобранные семена гороха.)

## Рыболовный дневник

Крафтится из **Книги + Крючка №12 + Кожи** (без формы), читается по ПКМ. Шесть вкладок:

| Вкладка | Содержимое |
|---|---|
| **Рыбы** | Бестиарий — все виды, ваш счёт и личный рекорд, и полная страница «как поймать» (водоём, глубина, ширина, биомы, лучшие условия, наживки, снасть), читаемая прямо из того же профиля, что использует движок клёва |
| **Наживки** | Все наживки, приманки и прикормки, и кого чем привлекать |
| **Снаряжение** | Удилища, катушки, лески и оснастки с рецептами крафта и диапазонами совместимости |
| **Задания** | Цепочка выше, с прогрессом и кнопками «Забрать!» |
| **Навыки** | Дерево перков и остаток очков |
| **Гайды** | Двенадцать написанных страниц-инструкций |

Полка гайдов охватывает: фрикцион, запас прочности, живца, *свой водоём*, игру приманкой, топвотер, троллинг, морских гигантов, легендарных рыб, рынок и заказ дня, рыбалку вдвоём и снастевой станок.

Строка заголовка выглядит так: *«Рыболов: ур. N (ранг) — X XP, до след. Y»*.

## Команды оператора

| Команда | Действие |
|---|---|
| `/rffish unlockall` | Заполняет дневник — каждый вид в максимальном весе, 120 поимок всего, 10 трофеев, 40 поимок со льда и XP на 25-й уровень. Все цели заданий становятся выполненными. |
| `/rffish reset` | Стирает ваши записи, XP, навыки и прогресс заданий. |

Обеим нужен уровень прав 2.

Есть ещё **клиентская** команда `/rfrod` — ею настраивают положение удочки в руке и анимацию изгиба бланка (`show`, `reset`, `set`, `add`, `bend`, `tip`). Это инструмент разработки, на геймплей она не влияет никак.
