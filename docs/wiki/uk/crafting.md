# Довідник з крафту

Усі рецепти, які додає мод. У рецептів за формою схема сітки записана як `ряд / ряд / ряд`, де `·` — порожня клітинка.

У предметів із позначкою **лише торгівля** або **лише завдання** рецепту немає взагалі — див. [Рибак](villager.md) і [Прогресія](progression.md).

---

## Вудилища

Усі — за формою. Кожному бланку з котушкою потрібна нитка на обмотку пропускних кілець.

| Вудилище | Схема | Позначення |
|---|---|---|
| Вудка з палиці | `··S / ·S· / S··` | S = Палиця |
| Бамбукова вудка | `··b / ·b· / b··` | b = Бамбук |
| Зимова вудка | `··N / ·S· / S··` | N = Залізний самородок, S = Палиця |
| Махове вудилище | `··b / ·b· / is·` | b = Бамбук, i = Залізний злиток, s = Нитка |
| Ультралайт | `··b / sb· / i··` | b = Бамбук, s = Нитка, i = Залізний злиток |
| Спінінг | `··b / si· / i··` | b = Бамбук, s = Нитка, i = Залізний злиток |
| Фідерне вудилище | `··g / si· / ii·` | g = Золотий злиток, s = Нитка, i = Залізний злиток |
| Донне вудилище | `·gg / si· / ii·` | g = Золотий злиток, s = Нитка, i = Залізний злиток |
| Коропове вудилище | `··d / si· / ig·` | d = Діамант, g = Золотий злиток, s = Нитка, i = Залізний злиток |
| Морський спінінг | `··p / si· / id·` | p = Призмариновий уламок, d = Діамант, s = Нитка, i = Залізний злиток |
| Серфове вудилище | `·pp / si· / id·` | p = Призмариновий уламок, d = Діамант, s = Нитка, i = Залізний злиток |
| Човнове вудилище | `··c / si· / id·` | c = Призмаринові кристали, d = Діамант, s = Нитка, i = Залізний злиток |
| Тролінгове вудилище | `··n / si· / id·` | n = Мушля навтилуса, d = Діамант, s = Нитка, i = Залізний злиток |

Чотири морські різняться лише **вершинкою**. Матеріали для ремонту на ковадлі перелічені у [Вудилищах](rods.md).

## Волосінь

Усі — за формою, навколо **кільця з 8 Ниток** (`SSS / S?S / SSS`).

| Результат | Центр кільця |
|---|---|
| Монофіл 0.10 **×2** | *(порожньо)* |
| Плетінка 0.16 **×2** | Перетинка фантома |
| Флюорокарбон 0.14 **×2** | Аметистовий уламок |
| Наступний діаметр **×1** | Попередня волосінь того самого матеріалу |

Ланцюжки покращення, один крафт на крок:

| Матеріал | Ланцюжок |
|---|---|
| Моно | 0.10 → 0.14 → 0.18 → 0.25 → 0.30 → 0.40 → 0.50 → 0.60 → 0.70 → 0.80 |
| Плетінка | 0.16 → 0.20 → 0.25 → 0.30 → 0.40 → 0.50 → 0.60 |
| Флюорокарбон | 0.14 → 0.16 → 0.20 → 0.25 → 0.30 → 0.40 |

## Гачки

Усі — без форми. Чим більший номер, тим менший гачок.

| Результат | Інгредієнти |
|---|---|
| Гачок №16 **×2** | Залізний самородок |
| Гачок №14 | Гачок №16 + Залізний самородок |
| Гачок №12 | Гачок №14 + Залізний самородок |
| Гачок №10 | Гачок №12 + Залізний самородок |
| Гачок №8 | Гачок №10 + Залізний самородок |
| Гачок №6 | Гачок №8 + Залізний самородок |
| Гачок №4 | Гачок №6 + Залізний самородок |
| Гачок №2 | **лише торгівля** (рибак-майстер) |
| Гачок №1 | **лише торгівля** (рибак-майстер) |

Усі дев'ять розмірів гачків складають тег `riverfishing:hooks`, який використовують рецепти приманок. Зверніть увагу: у №2 і №1 власного рецепту немає — рибак-майстер є їхнім єдиним джерелом.

## Оснастки

> **Це базові рецепти.** Зв'язана руками оснастка виходить із запасною масою свого типу — вибору
> вам ніхто не дає. Щоб отримати оснастку **потрібної вам ваги**, в'яжіть її на
> **[снастевому столі](tackle-station.md)**. Наполегливо радимо: саме вага має вкладатися у
> [вікно тесту](rods.md#завантаження-бланка-тестове-вікно) вашого бланка, а верстатні оснастки
> приходять уже з гачками в слотах.

Крафтяться лише шість змінних донних оснасток. Примітивна, Легка поплавкова, Поплавкова, Зимова й Хижацька оснастки вбудовані у свої бланки, їх не зробити й не потримати в руках.

| Оснастка | Тип | Інгредієнти |
|---|---|---|
| Донна оснастка | без форми | Нитка + 2 × Залізний самородок |
| Фідерна оснастка | за формою `n·n / nsn` | n = Залізний самородок, s = Нитка |
| Флет-фідер | за формою `nnn / nsn` | n = Залізний самородок, s = Нитка |
| Груша (3 гачки) | без форми | 3 × Нитка + 2 × Залізний самородок |
| Коропова оснастка | без форми | 2 × Нитка + Слизова кулька + Залізний самородок |
| Сомова оснастка | без форми | 2 × Нитка + Залізний злиток + Залізний самородок |

Усі шість можна зв'язати й на [снастевому столі](tackle-station.md) під обрану вагу — і виходять вони вже з гачками в слотах.

## Приманки

> **Це базові рецепти, і вони коштують вам маси приманки.** Скрафчена руками приманка йде **без
> штампа ваги**, а це гра читає як **0 г** — вона нічого не додає до вашого закиду й не працює на
> [фільтр розміру приманки](tackle-station.md#2-фільтр-розміру-приманки-лише-приманки), тож ніколи не
> добирає собі рибу. В'яжіть приманки на **[снастевому столі](tackle-station.md)** — вибирайте
> грами й отримуйте справжній розмір. Два найважчі класи (морські розміри) є лише там.

Інгредієнт `h` — це тег `riverfishing:hooks` (№16–№4).

| Приманка | Тип | Інгредієнти |
|---|---|---|
| Обертова блешня | за формою `n / i / h` | n = Залізний самородок, i = Залізний злиток, h = гачок |
| Коливна блешня | за формою `g / h` | g = Золотий злиток, h = гачок |
| Кастмастер | без форми | 2 × Залізний злиток + гачок |
| Кренк | без форми | Залізний злиток + Залізний самородок + гачок |
| Джиг | без форми | Залізний злиток + Нитка + гачок |
| Поппер | без форми | Залізний самородок + Бамбук + гачок |
| Воблер | — | **[Снастевий стіл](tackle-station.md)** або рибак (ранг фахівця) |
| Силіконова приманка | — | **[Снастевий стіл](tackle-station.md)** або рибак (ранг підмайстра) |

### Фарбування приманки

**Особливий рецепт**: будь-яка одна штучна приманка плюс один чи кілька **барвників** у сітці, де завгодно, повертають приманку зі змішаним кольором — точно як зі шкіряною бронею. Див. [колір приманки](rigs-and-baits.md#фарбування-приманок).
