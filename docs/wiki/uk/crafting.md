# Довідник з крафту

Усі рецепти, які додає мод. У рецептів за формою схема сітки записана як `ряд / ряд / ряд`, де `·` — порожня клітинка.

У предметів із позначкою **лише торгівля** або **лише завдання** рецепту немає взагалі — див. [Рибак](villager.md) і [Прогресія](progression.md).

---

## Вудилища

Від 0.10.0 крафтяться лише чотири найпростіші бланки; решту вудилищ **купують зібраними в [рибака](villager.md)** (рядок «як здобути» в щоденнику так і каже). Усі — за формою; бланку з котушкою потрібна нитка на обмотку пропускних кілець.

| Вудилище | Схема | Позначення |
|---|---|---|
| Вудка з палиці | `··S / ·S· / S··` | S = Палиця |
| Махове вудилище | `··b / ·b· / is·` | b = Бамбук, i = Залізний злиток, s = Нитка |
| Ультралайт | `··b / sb· / i··` | b = Бамбук, s = Нитка, i = Залізний злиток |
| Нахлистове вудилище | `··b / sb· / bn·` | b = Бамбук, s = Нитка, n = Залізний самородок |

**Лише торгівля:** Бамбукова, Зимова, Спінінг, Фідерне, Донне, Коропове, Морський спінінг, Серфове, Човнове й Тролінгове. Матеріали для ремонту на ковадлі перелічені у [Вудилищах](rods.md).

---

## Котушки

Крафтяться дві, без форми; решта дев'ять (2000, 3000, 5000, 6000, 7000, 8000, 10000, 12000, 14000) — **лише торгівля**: їх продає [рибак](villager.md), а дві приходять нагородами за [завдання](progression.md#ланцюжок-завдань).

| Котушка | Інгредієнти |
|---|---|
| Котушка 1000 | 2 × Залізний злиток + Редстоуновий пил |
| Котушка 4000 | 3 × Залізний злиток + Мідний злиток + 2 × Редстоуновий пил |

Предмета «Котушка 9000» не існує.

---

## Волосінь

Усі — за формою, навколо **кільця з 8 Ниток** (`SSS / S?S / SSS`).

| Результат | Центр кільця |
|---|---|
| Монофіл 0.10 **×2** | *(порожньо)* |
| Флюорокарбон 0.14 **×2** | Аметистовий уламок |
| Наступний діаметр **×1** | Попередня волосінь того самого матеріалу |

Плетінка 0.16 рецепту більше не має — її продає [рибак](villager.md). Ланцюжки покращення, один крафт на крок; діаметр **жирним** не крафтиться — його купують, і ланцюжок іде далі вже від нього:

| Матеріал | Ланцюжок |
|---|---|
| Моно | 0.10 → 0.14 → 0.18 → 0.25 → 0.30 → 0.40 · **0.50, 0.60, 0.70, 0.80** лише торгівля |
| Плетінка | **0.16** → 0.20 → 0.25 · **0.30, 0.40, 0.50, 0.60** лише торгівля |
| Флюорокарбон | 0.14 → 0.16 · **0.20** → 0.25 → 0.30 · **0.40** лише торгівля |

### Ремонт волосіні

Будь-яка волосінь у **центрі** сітки й **чотири Нитки** з чотирьох її боків (`·S· / SLS / ·S·`) повертають ту саму волосінь **свіжою** — [знос](reels-and-lines.md) знято. Будь-який діаметр будь-якого матеріалу, куплена вона чи скрафчена.

## Гачки

Усі — без форми. Чим більший номер, тим менший гачок.

| Результат | Інгредієнти |
|---|---|
| Гачок №16 **×2** | Залізний самородок |
| Гачок №14 | Гачок №16 + Залізний самородок |
| Гачок №12 | Гачок №14 + Залізний самородок |
| Гачок №10 | Гачок №12 + Залізний самородок |
| Гачок №8 | Гачок №10 + Залізний самородок |
| Гачок №6 | Гачок №8 + Залізний самородок |
| Гачок №4 | Гачок №6 + Залізний самородок |
| Гачок №2 | **лише торгівля** (рибак-майстер) |
| Гачок №1 | **лише торгівля** (рибак-майстер) |

Усі дев'ять розмірів гачків складають тег `riverfishing:hooks`, який використовують рецепти приманок. Зверніть увагу: у №2 і №1 власного рецепту немає — рибак-майстер є їхнім єдиним джерелом.

## Оснастки

**Жодна оснастка рецепту крафту не має.** Шість змінних донних — Донна, Фідерна, Флет-фідер, Груша, Коропова й Сомова — в'яжуться на **[снастевому столі](tackle-station.md)** під вагу, яку обрали ви, бо саме вага має вкластися у [вікно тесту](rods.md#завантаження-бланка-тестове-вікно) вашого бланка; виходять вони вже з гачками в слотах. (До 0.10.0 зв'язана руками оснастка мала запасну масу, вибору ніхто не давав, тож рецепти в сітці не вчили нічого, чого стіл не вчить краще.)

Примітивна, Легка поплавкова, Поплавкова, Зимова й Хижацька оснастки вбудовані у свої бланки, їх не зробити й не потримати в руках.

## Повідці й поплавок

Усі — без форми.

| Предмет | Інгредієнти |
|---|---|
| Сталевий повідець | Нитка + Залізний самородок |
| Флюорокарбоновий повідець | **лише торгівля** — у [рибака](villager.md) |
| Титановий повідець | **лише торгівля** — у рибака або як нагорода за [завдання](progression.md#ланцюжок-завдань) |
| Поплавок | Бамбук + Перо |

## Приманки

**Жодна приманка не має рецепту в сітці** — ані обертова, ані коливна блешня, ані родина воблерів, джиг, кастмастер, спіннербейт, цикада, свімбейт, вэкі-черв'як, поппер, кренк чи мормишка. Їх **в'яжуть на [снастевому столі](tackle-station.md)** — вибираєте грами, дістаєте справжній розмір і гачок на свій смак — або купують у [рибака](villager.md). (Приманка з сітки не мала штампа ваги, і гра читала її як 0 г: до закиду нічого, [фільтру розміру приманки](tackle-station.md#2-фільтр-розміру-приманки-лише-приманки) читати нічого. Тримати таке не було сенсу.) Два найважчі класи (морські розміри) є лише на столі. Єдиний рецепт для приманок, що лишився, — фарбування:

### Фарбування приманки

**Особливий рецепт**: будь-яка одна штучна приманка плюс один чи кілька **барвників** у сітці, де завгодно, повертають приманку зі змішаним кольором — точно як зі шкіряною бронею. Див. [колір приманки](rigs-and-baits.md#фарбування-приманок).

## Наживки

| Наживка | Тип | Інгредієнти |
|---|---|---|
| Тісто | без форми | Пшениця + Відро води |
| Хлібний м'якуш **×4** | без форми | 1 × Хліб |
| Бойли **×4** | без форми | 2 × Пшениця + Яйце + Цукор |
| Живець | **особливий** | Одна спіймана риба вагою **до 150 г**, сама в сітці — наживка зберігає вагу цієї риби |

Черв'як, Опариш, Мотиль і Куряча печінка беруться з копання та випадають із мобів; Кукурудза, Горох і Перлівка — з [наживкових грядок](blocks.md#наживкові-культури). Див. [Інструменти](tools.md#звідки-береться-наживка).

## Прикормка

| Прикормка | Тип | Інгредієнти |
|---|---|---|
| Базова прикормка **×2** | без форми | Насіння пшениці + Хліб — *основа; усе інше [підмішують](groundbait.md) у неї* |
| Прикормовий ґрунт **×4** | без форми | Земля — *баласт, яким суміш роблять піснішою* |
| Будь-яка суміш | без форми | Базова прикормка + до 8 компонентів у сітці — одна комірка це один предмет, а їстівний предмет на вході це прикормка на виході |
| Гранульована прикормка | — | **лише завдання** (*Спіймай лина*, етап 2) |

## Блоки

| Блок | Тип | Інгредієнти |
|---|---|---|
| Рибальська ятка | без форми | Діжка + 2 × Нитка + Залізний злиток |
| Род-под (1 слот) | за формою `s·s / ·s· / ·s·` | s = Палиця |
| Род-под (3 слоти) | за формою `n·n / iii / i·i` | n = Залізний самородок, i = Залізний злиток |
| Пастка на живця | за формою `s·s / shs / s·s` | s = Палиця, h = Нитка |
| Ферма черв'яків | за формою `PPP / PDP / PPP` | P = будь-які дошки, D = Ґрунт |
| Ферма опариша | за формою `PPP / PFP / PPP` | P = будь-які дошки, F = Гнила плоть |
| Акваріум | за формою `GWG / RKR / PSP` | G = Скло, W = Відро води, R = Гравій, K = Ламінарія, P = будь-які дошки, S = будь-яка табличка |
| Міні-акваріум | — | **рецепту немає** |

## Готування

| Результат | Спосіб | Вхід | Час | XP |
|---|---|---|---|---|
| Смажене філе | Коптильня | Сире філе | 100 тіків | 0.2 |
| Смажене філе | Піч | Сире філе | 200 тіків | 0.2 |
| Смажене філе | Багаття | Сире філе | 600 тіків | 0.2 |

Сире філе дає [Філейний ніж](tools.md#філейний-ніж) — одне на 200 г риби, але не більше стака з одного екземпляра. Цей самий предмет — універсальна морська насадка й компонент прикормки.
