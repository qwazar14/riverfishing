# 3D-модели: привязки имён элементов (Blockbench)

Конвейер (§rod-3d) узнаёт детали **по именам элементов**. Переименуешь — инструмент либо
откажется работать, либо молча пропустит деталь. После любой правки: `node tools/check_rod_assets.js`.

## Инварианты для любой удочки

| правило | почему |
|---|---|
| комель на **x = 32** | позы рук (`RodHandTransform` TP3/FP3) хватают именно там |
| ось бланка **y = 10.5, z = 8.5** | цепь изгиба, леска и посадка катушки считают от неё |
| координаты в **−16..32** | предел формата; выход = модель не грузится |
| углы поворота только **0 / ±22.5 / ±45** | иные — `JsonParseException`, модель не грузится целиком |
| ключи слотов текстуры — любые, но грани должны ссылаться на объявленные | установщик переписывает только *значения* слотов |
| `texture_size` = реальному размеру PNG | иначе сетка в Blockbench не совпадает с тем, что рисует игра |
| кончик = элемент с минимальным x | из него берутся `BLANK_TIP_X` (якорь лески) и `tip` пути нити |

## Безкатушечные (stick, bamboo, pole, winter) — `takesReel=false`, ни колец, ни катушкодержателя

| имя | что это | кто на него завязан |
|---|---|---|
| `grip` | рукоять | текстуратор красит в цвет рукояти фидера |
| `section_1..N` | секции бланка, от комля к кончику, каждая тоньше предыдущей | генератор падает, если не тоньше |
| `node_N` / `ferrule_N` | колено бамбука / муфта маховой — **центр = сустав цепи** | `split_rod.js` (`jointAt`), едет с вершинковым сегментом и закрывает щель |
| `tip_whipping` | обмотка на кончике, к ней «вяжется» леска; у зимней = сторожок | красится в цвет квивертипа |
| `stick_butt/mid/tip`, `twig_N`, `tip_knob` | только у палки: три палки внахлёст, сучки, шишка на конце | `gen_stick_rod.js`; `stick_butt` обязан сидеть на оси |

## Катушечные (остальные 9) — `takesReel=true`

| имя | что это | кто на него завязан |
|---|---|---|
| `butt_cap` | набалдашник | текстуратор |
| `rear_grip`, `fore_grip` | рукояти вокруг держателя | текстуратор |
| `reel_seat` | катушкодержатель, **низ строго y = 9.45** | лапка катушки стыкуется в эту грань; `REEL_SEAT_DX` в рендерере = центр держателя − 19.5 (фидерный) |
| `blank_1..N` (у фидера: `blank_butt/mid/tip`, `quivertip`) | секции бланка | сегментация (`split_rod.js` members), quivertip красится ярким |
| `guide_1..N` | кольца: **нулевая толщина по X**, висят под осью, бланк проходит сквозь рамку | `gen_line_paths.js` ведёт нить через центры; спрайт кольца 5×5/3×3, дырка — прозрачностью; грани кроме east/west — UV `[0,0,0,0]` |
| `tip_top` | тюльпан | конец пути нити |

## Катушка — один мастер `3D/reels/reel_4000.json`, размеры производные

| имя | что это | кто на него завязан |
|---|---|---|
| `foot` | лапка — **не масштабируется**, якорь масштаба | аудит требует идентичности на всех 11 размерах |
| `stem`, `body`, `rotor` | ножка, корпус, ротор | текстуратор (металл держателя) |
| `spool` | шпуля | на неё рисуется полоса намотанной лески |
| `drag_knob` | фрикцион | акцентный цвет |
| `bail`, `line_roller` | дужка, ролик | цвет колец |
| `handle_arm` | **рычаг кривошипа**: ось вращения = редуктор (19.45, 7.0), рычаг радиально вниз | рендерер машет им при вываживании; ось должна лежать внутри рычага |
| `handle_knob` | кноб на конце рычага, центр по x = 19.45, по y **не на оси** (радиус орбиты!) | контрповорот вокруг собственного центра; соосный кноб = генератор падает |

## Порядок после правки модели

```
node tools/install_rod_model.js <kind>     # цельные удочки (текстура рядом: texture.png)
node tools/split_rod.js <feeder|pole|bamboo>   # сегментные (напечатает суставы для Java)
node tools/gen_line_paths.js               # если двигал кольца/кончик
node tools/gen_reel_texture.js && node tools/gen_reels.js   # если правил мастер катушки
node tools/check_rod_assets.js             # всегда; зелёное = можно собирать
```

Java-константы, которые обязаны совпадать с моделями (аудит сверяет сам): `BLANK_TIP_X`,
`BLANK_JOINTS_X`, `REEL_SEAT_DX` в `RodItemRenderer`; физика — `rod_physics.json`
(живой тюнинг: `/rfrod phys rod stiffness|damping|whip <v>` с удочкой в руке, печатает строку для вставки).
